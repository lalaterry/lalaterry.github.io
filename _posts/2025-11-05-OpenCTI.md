# 安裝
需要先安裝docker、docker-compose、jq

先創建資料夾，然後用git下載，會看到docker資料夾
```
mkdir -p /path/to/your/app && cd /path/to/your/app
git clone https://github.com/OpenCTI-Platform/docker.git
cd docker
```

環境設定
因為是ELK進行，所以些環境設定需要檢查，但目前看來下載的檔案都已經設定好

docker-compose.yml
```
  elasticsearch:
    environment:
      - thread_pool.search.queue_size=5000
```

rabbitmq.conf
```
max_message_size = 536870912
consumer_timeout = 86400000
```

初始設定`.env`
OPENCTI_ADMIN_EMAIL=
OPENCTI_ADMIN_PASSWORD=
記得修改帳號密碼!
OPENCTI_BASE_URL=http://localhost:8080
有固定IP也可替換，預設port建議不要改
```
cd ~/docker
(cat << EOF
OPENCTI_ADMIN_EMAIL=admin@opencti.io
OPENCTI_ADMIN_PASSWORD=ChangeMePlease
OPENCTI_ADMIN_TOKEN=$(cat /proc/sys/kernel/random/uuid)
OPENCTI_BASE_URL=http://localhost:8080
OPENCTI_HEALTHCHECK_ACCESS_KEY=$(cat /proc/sys/kernel/random/uuid)
MINIO_ROOT_USER=$(cat /proc/sys/kernel/random/uuid)
MINIO_ROOT_PASSWORD=$(cat /proc/sys/kernel/random/uuid)
RABBITMQ_DEFAULT_USER=guest
RABBITMQ_DEFAULT_PASS=guest
ELASTIC_MEMORY_SIZE=4G
CONNECTOR_HISTORY_ID=$(cat /proc/sys/kernel/random/uuid)
CONNECTOR_EXPORT_FILE_STIX_ID=$(cat /proc/sys/kernel/random/uuid)
CONNECTOR_EXPORT_FILE_CSV_ID=$(cat /proc/sys/kernel/random/uuid)
CONNECTOR_IMPORT_FILE_STIX_ID=$(cat /proc/sys/kernel/random/uuid)
CONNECTOR_EXPORT_FILE_TXT_ID=$(cat /proc/sys/kernel/random/uuid)
CONNECTOR_IMPORT_DOCUMENT_ID=$(cat /proc/sys/kernel/random/uuid)
CONNECTOR_ANALYSIS_ID=$(cat /proc/sys/kernel/random/uuid)
SMTP_HOSTNAME=localhost
EOF
) > .env
```

在啟動前需要設定`vm.max_map_count`
```
sudo sysctl -w vm.max_map_count=1048575
```

如果要永久生效，加入`/etc/sysctl.conf`
```
vm.max_map_count=1048575
```


# 啟動

直接啟動docker，如果需要權限加上sudo
```
docker-compose up -d
```

啟動成功之後直接瀏覽localhost:8080
