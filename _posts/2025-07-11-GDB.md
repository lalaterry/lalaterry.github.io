# GDB - Command

* checksec：檢查保護機制
* info functions : 查看functions
* break function_name / b：在 function_name 下斷點
* run / r：開始執行程式
* next / ni：執行下一行，不進入函數
* step / si：執行下一行，並進入函數內部
* continue / c：繼續執行程式，直到下一個斷點
* info registers：檢視所有暫存器內容檢視所有暫存器內容
* x/10gx $rsp：檢視堆疊內容（10 個 8-byte slot）
* x/20s address：以字串格式顯示記憶體內容
* p variable_name：打印變數的值
* disassemble function_name：反組譯指定函數
* finish：直接執行至函數返回
* bt：顯示當前堆疊回溯 (backtrace)
* vmmap：查看 memory mapping
