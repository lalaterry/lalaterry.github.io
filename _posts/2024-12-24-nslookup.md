```
nslookup -type=mx example.com 8.8.8.8
```

### 互動模式
```
nslookup
> set type=mx //指定查詢類型
> server 8.8.8.8 //指令dns server
Default server: 8.8.8.8
Address: 8.8.8.8#53
> issdu.com.tw
Server:         8.8.8.8
Address:        8.8.8.8#53

Non-authoritative answer:
issdu.com.tw    mail exchanger = 10 issdu-com-tw.mail.protection.outlook.com.

```

* NS(Name Server) 紀錄domain的伺服器
* A(Address)將domain解成IP
* AAAA(IPv6 Address)將domain解成IPv6
* MX(Mail Exchange)指定mail的伺服器
* PTR(Pointer)將IP轉成domain
* CNAME(Canonical Name)創建一個domain指向domain
* TXT(Text)存SPF、DKIM、DMARC等資訊
